The derivative of exp and log, in your wiggle language

Same question you used for + and ×: nudge the input by a tiny step, how much does the output wiggle? The ratio (out-wiggle / in-wiggle) is the derivative. Let's carry that straight into e^x and log.

0. The two you already own

For a sum, the step passes straight through: nudge x, the output moves the same amount, so the slope is 1. For a multiply, each input step is worth ‘the other factor’ of output, so 3x has slope 3. Notice both slopes are constant — straight lines. exp and log are curves, so their slope will change as you move along.

1. e^x : the output wiggles by its own height

Take the multiply idea and make the multiplier the output itself. Ask ‘nudge x a little, how much does e^x move?’ Answer: by an amount equal to how tall e^x already is. That is the whole meaning of d/dx(e^x) = e^x.

Same size input step at every dot. The output jump is tiny down low and huge up high — because the jump equals the current height.

Percentage lens: a step in x doesn't add a fixed amount, it adds a fixed percentage. Where e^x = 5 a nudge grows it by 5×step; where e^x = 100 the same nudge grows it by 100×step — same %, twenty times the wiggle. So ‘how much it wiggles’ = ‘how big it is’.

physical anchor

A bank balance on continuous interest. $100 earns 20× more dollars per second than $5 — same rate, bigger absolute growth because there's more to grow. e is the base tuned so that rate is exactly ‘1 per unit of x’, which makes the growth speed numerically equal the balance. (Bernoulli's compound-interest limit (1 + 1/n)^n → e.)

2. log(x) : the output wiggles by the % change in x (= 1/x)

Flip it. exp says ‘add to x → multiply the output’. log is the mirror: ‘multiply x → add to the output’. So log reacts to the percentage change in x, not the absolute change. Nudge x by Δx; the fraction that step represents is Δx / x, and that's how much log moves. Divide the step by x → slope = 1/x.

Same size input step again. Down at x = 0.5 the step is a big % of x, so log jumps a lot. Up at x = 4 it's a tiny %, so log barely moves. Small x = twitchy, big x = sluggish.

Here's the ‘percentage’ claim made literal: equal multiplies in x become equal adds in log.

where this shows up

Every ‘log scale’ you've met — decibels, Richter, pH, stock returns — exists for this exact reason: they turn percentage / multiplicative change into equal steps of distance. Napier built logs in 1614 to turn multiplication into addition, and this 1/x slope is the calculus fingerprint of that trick.

3. Why they're reciprocals: the mirror

exp's wiggle grows with size; log's wiggle shrinks with size — and the two slopes are reciprocals (h vs 1/h). That's not a coincidence: log is exp reflected across y = x. Reflecting a ramp swaps its rise and its run, so a slope of h becomes a slope of 1/h.

The blue point sits on e^x with slope e (≈ 2.72). Reflect it across y = x and you land on the red log curve, where the slope is 1/e (≈ 0.37). Rise and run traded places.

one-liners

e^x: the output wiggles by its own current height (so it steepens forever). log(x): the output wiggles by the percentage change in x, which is step / x, so it flattens as x grows. They're mirror images, which is why one slope is the other flipped.
