Building (B, T, C) from a dummy sentence

input = "this is a new poyem that a shake speaer wrote"  ·  block size = 3

Stage 1

Chop the text into chunks of 3

Each colored group of 3 characters is one chunk. The chunk length (3) is the block size. Space is shown as ·.

✔ Your slicing idea is exactly right.

One fix: the real code grabs chunks from random spots in the text (they can overlap), not by cutting cleanly in order. But for understanding the shape, this neat cut-every-3 picture is perfect.
Stage 2

Stack a few chunks → that stack is a batch

Take 2 chunks ("thi" and "s·i") and stack them into a grid. This whole grid is one batch.

t0t1t2
chunk 0thi
chunk 1s·i
B = 2 → rows = how many chunks stacked T = 3 → columns = position in the chunk

Shape so far = (B,T) = (2,3). Each cell holds just one character. There is no C yet.

Stage 3

Replace each char with a vector → C is born

A net can't use the letter 't' directly. We describe each char with a little list of numbers. Let's use 2 numbers per char (C = 2):

t → [0.7, -1.2]
h → [0.1, 0.9]
i → [-0.4, 0.3]
s → [1.1, 0.0]
· → [0.2, -0.7]

Now every cell holds a stack of 2 numbers — that stack going "into the page" is the channel dimension:

t0t1t2
chunk 0 0.7
-1.2		 0.1
0.9		 -0.4
0.3
chunk 1 1.1
0.0		 0.2
-0.7		 -0.4
0.3
C = 2 → depth = how many numbers describe each character
The key moment: C did not exist at the raw-character grid. It is born here, the instant each character turns into a vector of numbers (an embedding).
Stage 4

Read the final shape

(B, T, C) = (2, 3, 2)

"2 chunks × 3 positions each × 2 numbers per character"

B = 2how many chunks are stacked & processed in parallel (they never talk to each other — stacking is only for GPU speed) T = 3which position inside a chunk (t0, t1, t2). Called time because a sequence unfolds one token per tick. = block size. C = 2how many numbers describe the character at each position. Borrowed from images: RGB = 3 color channels.
Straight to Karpathy's toy line B,T,C = 4,8,2 (@43:21):
 • he stacks 4 chunks  (we did 2)
 • each chunk is 8 chars long  (we did 3)
 • each char = 2 numbers  (same as us)
Only the numbers differ — the meaning is identical.
