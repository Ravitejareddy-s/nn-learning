Three ways to read a sequence

Same 8-character input m a c h i n e s in every panel. Blue = input characters. Colored boxes = computed values (same color = same shared weights). Click any node to light up which inputs it actually depends on.

Click a colored node to see its receptive field (which inputs feed it).

1. CNN local · parallel · shallow

One small filter (kernel 2) slides across. Each output is computed independently from a fixed 2-input window — no baton passed between them, so they could all be computed at once. Click an o box: only its 2 inputs light up. Reach is fixed and small.

all outputs share the one filter's weights.

2. RNN whole history · sequential · deep

One cell, reused at every step, carries a running memory h forward — the baton (green horizontal arrows). Each h = tanh(Linear(concat(prev h, this input))). Click the red next node: all 8 inputs light up, because the memory chains back through every step. That long chain is also why it is a "very very deep network" and why it's slow (step 3 must wait for step 2).

every hidden box reuses the same one cell's weights.

3. WaveNet whole history · parallel · log-depth

A tree of small conv layers fuses pairs, then pairs-of-pairs, doubling reach at each level. Click the top next node: all 8 inputs light up like the RNN — but it got there in only 3 layers (log₂8), and each layer's boxes are independent so they run in parallel like a CNN. WaveNet is the bridge: RNN's long memory, CNN's parallel speed.

layer 1 layer 2 layer 3 — weights shared within a layer (across positions), different per layer.

The one-glance summary

To let position t depend on the very first character:
• CNN (single layer): can't — reach is stuck at the window size.
• RNN: yes, but the signal travels 8 sequential steps down the chain (deep → gradients fade — the disease the LSTM cures).
• WaveNet: yes, in 3 parallel layers (log-depth tree).
