The shape (B, T, C) = (4, 8, 2)

Lecture 7 · the toy example at 43:21 · "a spreadsheet with depth"

B — batch = rows (chunks stacked) T — time = columns (position in chunk) C — channels = depth (numbers per token)

Each little cell isn't one number — it holds a stack of C = 2 numbers (shown filled-in for chunk 0). That stack going "into the page" is the channel dimension.

Read the shape out loud

(4, 8, 2) = 4 chunks × 8 positions each × 2 numbers per token

B = batchHow many chunks are stacked and processed in parallel. They never talk to each other — stacking is purely for GPU speed. T = timeWhich position inside a chunk (1st char, 2nd char, ...). A sequence unfolds one token per "tick", hence time. Equals the block size. C = channelsThe length of the vector used to describe the token sitting at each position. Borrowed from images (RGB = 3 color channels).

Where your mental model was missing C

At the raw input stage (xb, ~20:29) each cell is just one integer — the character index — so the tensor is only (B,T) = (4,8). No depth yet.

The C axis is born the moment each token becomes a vector — an embedding, or the 65 logits. That new third axis is the channels. In the toy example he just makes it up as C = 2 so the picture is small.

Your "hello" and "how i" were two rows of one batch (two values along B), not two separate batches. One batch = the whole 4-row stack fed together.
