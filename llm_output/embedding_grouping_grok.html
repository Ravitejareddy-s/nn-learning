Why the embedding groups similar letters

Lecture 3 · the "magic" Karpathy skipped — computed from your real names.txt (32,033 names)

The headline: the grouping is not a bonus feature — it is the lowest-loss configuration, forced by two facts: (A) there is only one shared network downstream, so a letter's embedding position is its entire identity; (B) that network is smooth, so nearby embeddings produce nearly identical predictions. Letters that must be predicted the same way get squeezed together; letters that must differ get pushed apart.

Measured on your data: average distributional similarity within the vowels is 0.78 vs 0.63 across all letter pairs — and every single vowel's nearest neighbors are other vowels (see below). That structure is in the raw statistics before any embedding is trained; the neural net just rediscovers it.

Fact A — one shared network, so position = identity

Your W1, b1, W2, b2 are the same for every character. There is no per-letter logic anywhere in the model. So the only thing the network can know about a character is where its embedding vector sits. Change the seat, change the meaning — that's the whole channel.

Fact B — the network is smooth

The MLP is a continuous, differentiable function: nudge an input embedding a little, the output prediction changes a little. So nearby embeddings → nearly identical predictions. To make the model predict differently for two letters, their embeddings must be far apart. This is the lever gradient descent pulls.

The squeeze (why GD herds them)

Seating-room analogy. The embedding space is seats; the shared network is one translator who reads your seat and shouts a prediction. One translator for everyone (Fact A), smooth rule — nearby seats get the same shout (Fact B). Training nudges each letter's seat to make its shout more correct. Vowels need the same shout, so they get herded into one corner; q needs a different shout, so it drifts away. Mapping: seat → C[i]  |  translator → shared MLP  |  shout → softmax prediction  |  nudging seats → gradient descent on embedding rows.

The origin story

This is the distributional hypothesis — linguist J.R. Firth, 1957: “you shall know a word by the company it keeps.” The embedding is a machine that turns company into position.

The paper you are reimplementing — Bengio et al. 2003, “A Neural Probabilistic Language Model” — was the first to learn these distributed representations with a neural LM, and this clustering was its headline result. A decade later, word2vec (Mikolov 2013) made the same phenomenon famous at word scale:

king − man + woman ≈ queen Paris − France + Italy ≈ Rome

So “it just does it” is really: one shared smooth network + gradient descent = distances in embedding space are forced to encode behavioral similarity. You rediscovered, live, the reason that entire line of research exists.
